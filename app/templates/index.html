匿名化规则说明

  • 年龄隐藏等级：0 = 原值；1 = 十岁段（如 42 → 40-49）；2 = 隐藏（***）。
  • 邮编隐藏等级：0 = 五位原值；1 = 仅保留前三位（如 100081 → 100**）；2 = 隐藏（***）。
  • 最多剔除 2 行；保留数据中每个（年龄, 邮编）组合须至少 3 人，且包含至少两种病种。
  • 在全部可行方案中选择两列隐藏等级之和最小者；同级先少剔除，再优先保留年龄精度。
  • 再次上传后，旧预览立即失效且不可发布；发布失败不会产生任何可下载残件。
  • 发布时，最终保留者的编号与当批病种、发布状态在同一事务原子保存。
  • 转归矩阵仅按两批共同保留的受试者号配对；未发布/发布失败批次不参与计算， 缺少对应关系的旧批次提示「无法计算」，不按零人处理。
  • 少于 3 人的格（含 0 人格）显示 ***，含隐藏格的行/列合计及总合计一并隐藏，无法反推人数；矩阵不返回受试者号。
